# Threads 投稿分析ツール

Threads 投稿データを貼り付けるだけで、伸びた投稿・弱い投稿・改善案・翌週の投稿方針を自動で出す静的HTMLツールです。

## 使い方

1. `index.html` をブラウザで開く
2. Google スプレッドシートから投稿データをコピー
3. 貼り付けて「分析する」

## 推奨カラム

最低限：

- 日付
- カテゴリ
- 投稿本文
- CTA/導線

あると分析精度が上がるカラム：

- インプレッション
- いいね
- コメント
- 保存
- リポスト
- プロフィールクリック
- LINE登録
- 無料相談
- 成約

## 判定ロジック

- 反応率 = (いいね + コメント + 保存 + リポスト) / インプレッション
- CTA率 = プロフィールクリック / インプレッション
- LINE転換率 = LINE登録 / プロフィールクリック
- 相談転換率 = 無料相談 / LINE登録
