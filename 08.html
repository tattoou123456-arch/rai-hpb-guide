以下のプロンプトを順番に使うことで、テーマ決めから本文完成まで一気通貫で対応できます。

STEP 1 — ブログネタ出し（月間カレンダー）
ネタ切れ解消
美容サロンのHPBブログ記事のネタを出してください。 【サロン情報】 ・業種：【ヘアサロン / ネイル / etc】 ・得意メニュー：【カット / カラー / etc】 ・エリア：【◯◯市 / ◯◯駅周辺】 ・ターゲット：【20〜40代女性 / etc】 【生成してほしいもの】 ・【◯月】のブログネタを12本（月3本 × 4週分） ・各ネタに以下を含めること： 1. タイトル案（地域名+施術名を含む） 2. 記事の概要（2〜3文） 3. 狙うキーワード 【注意点】 ・季節・イベントに合わせる ・SEOに有利な「◯◯する方法」「◯◯とは」形式のタイトルも含める ・リピーター獲得につながるネタも入れる
月初めに一気にネタ出しして、月間スケジュールを立てると習慣化しやすい
STEP 2 — SEOタイトル最適化
タイトル改善
HPBブログのSEOに強いタイトルを作ってください。 【記事テーマ】 【例：夏のダメージヘアケアについて】 【サロン情報】 ・エリア：【◯◯市 / ◯◯駅】 ・業種：【ヘアサロン / ネイル / etc】 【条件】 ・40文字以内 ・以下のパターンで各1案ずつ計5案を作成： 1. 「地域名＋メニュー名」で検索を狙ったもの 2. 「お悩み解決型」（〜で悩む方へ / 〜に効く） 3. 「数字入り」（◯選 / ◯つのポイント） 4. 「季節+施術」で旬感を出したもの 5. 「知らなきゃ損」系の興味喚起型 ・各タイトルに狙いキーワードを明記すること
Googleのサジェストで実際に検索されているキーワードを確認してから使うとさらに効果UP
STEP 3 — ブログ本文の完全生成
本文作成
HPBブログの記事本文を書いてください。 【記事タイトル】 【決定したタイトルを入力】 【サロン情報】 ・サロン名：【◯◯サロン】 ・エリア：【◯◯市 / ◯◯駅徒歩◯分】 ・得意施術：【◯◯】 ・使用薬剤・技術：【◯◯を使用 / ◯◯技法 etc】 【記事の目的】 【新規集客 / リピーター向け / ブランディング】 【条件】 ・400〜600文字 ・見出し（■ や ◆）で読みやすく構造化する ・専門用語は使わず、一般の方にわかりやすい言葉で ・施術の「ビフォーアフター」的なイメージを言葉で描写 ・最後に予約を促すCTA文を入れる ・HPBのサロン名と最寄り駅を自然に本文中に含める
Output Sample
■ 渋谷でダメージに悩む方へ
「カラーするたびに髪が傷む…」そんな声をよくいただきます。【サロン名】では、ダメージを最小限に抑えるイルミナカラーを使用。施術後はつやつやのサラ髪を実感いただけます。

■ こんな方におすすめ
・カラーを繰り返している方 ・パサつきが気になる方…
生成した本文に実際の写真を1〜2枚追加するとさらに効果的
施術事例レポート記事の生成
事例紹介
美容サロンの施術事例をブログ記事にしてください。 【施術情報】 ・メニュー名：【◯◯カラー+カット / etc】 ・お客様の悩み（Before）：【例：白髪が気になる・パサついている・etc】 ・施術内容：【使用薬剤・技法・ポイント】 ・仕上がり（After）：【例：艶感が出て若々しく / etc】 ・お客様の声：【例：「こんなに変わるとは思わなかった！」（任意）】 【サロン情報】 ・サロン名：【◯◯サロン】 ・エリア：【◯◯駅周辺】 【条件】 ・300〜400文字 ・「お客様の悩み→施術→仕上がり」の流れで構成 ・読んだ人が「自分もこうなりたい」と思えるような描写 ・プライバシーに配慮した表現（「お客様」「◯◯代の方」などに留める） ・最後にそのメニューのクーポンへの誘導文を入れる
施術後写真を撮影する習慣と組み合わせると強力なブログコンテンツになる
⚠️
投稿前に必ず確認： AI生成文はそのまま使わず、①実際のサロン情報と相違がないか ②薬剤・価格が正確か ③自然な日本語になっているかを確認してください。事実と異なる記載はHPBのガイドライン違反になる場合があります。
